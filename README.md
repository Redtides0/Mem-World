# Mem-World

**Memory-Augmented Action-Conditioned World Model for Robot Manipulation**

🎉 **CoRL 2026 · Oral Presentation**

[Project Page](https://redtides0.github.io/mem-world-page/) · [Paper](https://arxiv.org/abs/2606.18960)

Mem-World equips an action-conditioned world model with visual memory for long-horizon robot manipulation. Guided by future actions, it retrieves relevant historical observations to preserve scene consistency, improve policy evaluation, and generate useful trajectories for policy fine-tuning.
